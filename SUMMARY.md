# SPA Комментарии — кратко

## Что сделано

- Комментарии с ответами любой глубины. В интерфейсе видно 2 уровня, глубже ответы идут списком с подписью «в ответ Name» и переходом к родителю.
- Список по 25 комментариев. Сортировка по дате (по умолчанию новые сверху), имени, email и рейтингу.
- Лайки и дизлайки без регистрации.
- CAPTCHA, проверка HTML (`a`, `code`, `i`, `strong`), предпросмотр сообщения.
- Вложения:
  - картинки: 3 размера + WebP;
  - TXT;
  - видео: перекодирование в H.264/AAC для iOS/macOS + постер.
- Загрузка файлов напрямую в S3 по частям (multipart) через presigned URL, обработка в очереди.
- Обновления в реальном времени через WebSocket: новые комментарии и голоса.
- Интерфейс на русском и английском, светлая и тёмная тема.
- API-документация на Scalar: `/api/docs`.
- Всё запускается в Docker одной командой.

## Что использовалось

| Часть | Технологии |
|---|---|
| Backend | NestJS 11, TypeScript, Sequelize, class-validator, nestjs-i18n |
| Frontend | Next.js 16, React 19, CSS Modules |
| БД | PostgreSQL |
| Кеш / чтение списка | Meilisearch (если недоступен — читаем из Postgres) |
| Очереди | Bull + Redis |
| События | @nestjs/event-emitter |
| Real-time | Socket.IO |
| JWT | токен капчи (одноразовый) и анонимный токен для голосования |
| Файлы | S3 (DigitalOcean Spaces / LocalStack), CDN, sharp, ffmpeg |
| Документация | Swagger (OpenAPI) + Scalar |
| Тесты | Jest (unit 100%, e2e), Vitest + Testing Library, Playwright, autocannon (нагрузка) |
| Инфраструктура | Docker, Docker Compose |

## Нагрузка (1 ноутбук, 1M комментариев)

Чтение ~1 170 RPS, запись ~470 комм./с, голоса ~1 070/с, 1 000 WebSocket-клиентов (p99 39 мс). Подробно: `load/README.md`.
